# 墨影忍者 · 水墨五行跑酷

一款水墨风横版 2D 跑酷：**五行克制 + 三角色 + 五武器流派 + 五鬼王 + 关卡闯荡 + 每日挑战**。
纯 HTML5 Canvas 实现，零依赖、离线可玩（PWA），电脑与手机浏览器均支持。

## 运行方式

- 直接双击 `index.html` 即可游玩
- 或本地服务：`python -m http.server 8080` → `http://localhost:8080`
- 部署到任意静态托管（GitHub Pages / Gitee Pages / Vercel）即为在线 H5；已配置 PWA（manifest + sw.js），手机浏览器可"添加到主屏幕"离线玩
- 微信小游戏移植见 `docs/微信小游戏移植指南.md`

## 五行克制

**金 → 木 → 土 → 水 → 火 → 金（循环相克）**

- 武器、角色、鬼王、关卡主题各有元素；克制伤害 ×1.15，被克 ×0.9（Boss 血条旁实时提示）
- 角色对鬼王另有抵抗关系：角色克鬼王时奥义积蓄 ×1.5，被克 ×0.8
- 五武器：太刀(金) / 苦无(水) / 锁镰(木) / 雷刃(火) / 岩锤(土·重击3伤)
- 三角色：影(火) / 玄(土) / 凛(木)
- 五鬼王：骨魔将(金) / 藤魔(木) / 山魈(土) / 鸦天狗(水) / 鬼武士(火)，关卡终幕必为本关元素鬼王
- 五主题：木·竹林 / 水·雪夜 / 火·火山 / 土·黄沙 / 金·月窟（按关卡轮换）

| 动作 | 电脑 | 手机 |
|------|------|------|
| 跳跃 / 二段跳 | `空格` `W` `↑`（短按小跳） | 点屏幕右侧 / 「跃」按钮 |

## 玩法

- **四大武器流派**（开局可选，忍具匣随机轮换）：
  - 太刀·疾风：均衡近战，Lv2 起斩出刀气，Lv3 伤害翻倍；奥义·裂空斩
  - 苦无·残月：远程连发（1→2→3 发），Lv3 穿透；奥义·千本苦无
  - 锁镰·蚀骨：宽域重击（2 伤害），Lv2 起横扫卷钱，Lv3 连身后一起扫；奥义·锁镰旋舞
  - 雷刃·紫电：极速连斩 + 闪电链跳跃（Lv1 跳 1 目标 → Lv3 跳 3）；奥义·雷霆万钧
- **关卡系统**：主菜单选关闯荡，跑动时顶部显示关卡进度条；到达终点即通关，按受击次数评 ★1~3，通关解锁下一关；关卡越深难度与鬼王越强。
- **忍者皮肤**：功坊内购买/装备（墨影/赤焰/苍雷/白霜/金乌），成就「百人斩」解锁夜叉。
- **成就系统**：11 项成就（通关/击杀/鬼王/奥义/跑距/财富/无伤），达成弹 Toast，成就面板可查。
- **鬼王轮换**：鬼武士 → 鸦天狗 → 山魈，随关卡序号轮转，循环后增强；每关按 35%/70%/95% 进度出鬼王（第 1 关仅 80% 处一只）。
- 三点体力（功坊可扩），道具：守符护盾、磁石、樱心、忍具匣；武魂升级武器，满级解锁奥义槽。
- **每日挑战**：当日固定种子人人同图，单独记录今日最佳，每日首战 +200 钱。
- **忍者功坊**：铜钱永久强化——体魄/武魂亲和/聚财/疾风靴/奥义心得，各三级。
- 得分 = 距离 + 铜钱 × 5 + 击杀 × 15。

```
js/entities.js  忍者、粒子、障碍、铜钱、道具
js/chunks.js    关卡模板（按难度分层）
js/background.js 水墨视差背景
js/game.js      游戏主循环与状态机
js/main.js      启动引导
```
