# 微信小游戏移植指南

本游戏是纯前端 H5（Canvas + DOM UI），移植到微信小游戏（体验版）需要处理三件事：**运行时差异、UI 层差异、存储差异**。预计 1~2 天工作量。

## 一、前置准备

1. 注册微信小游戏账号（mp.weixin.qq.com），获得 AppID（测试号也行，可先用「测试号」做体验版）
2. 下载微信开发者工具，新建「小游戏」项目，选择空模板，填入 AppID

## 二、运行时适配（weapp-adapter）

小游戏没有 DOM/BOM，官方提供 `weapp-adapter`（开发者工具新建项目时可自动引入），
它模拟了 `window`、`document.createElement('canvas')`、`addEventListener` 等。

落地步骤：

1. 把本目录 `js/`、`css 无需`、资源复制进小游戏项目
2. `game.js`（小游戏入口）中：

```js
// 小游戏入口 game.js
require('libs/weapp-adapter');
var canvas = wx.createCanvas();   // weapp-adapter 已把主 canvas 挂到 window.canvas
// 然后按顺序加载逻辑脚本（小游戏无 <script>，用 require 或打包工具）
require('js/utils.js');
require('js/audio.js');
require('js/input.js');
require('js/entities.js');
require('js/chunks.js');
require('js/background.js');
require('js/game.js');
require('js/main.js');
```

3. 需要改动的 API 对照表：

| H5 | 小游戏 | 涉及文件 |
|----|--------|----------|
| `new AudioContext()` | `wx.createWebAudioContext()`（基础库 2.19+） | audio.js |
| `localStorage` | `wx.getStorageSync/setStorageSync` | utils.js 的 `store` |
| `requestAnimationFrame` | adapter 已提供；否则用 `canvas.requestAnimationFrame` | main.js |
| `performance.now()` | `Date.now()` | main.js |
| `navigator.serviceWorker` | 删除（无 SW） | main.js |
| 触摸事件 | `wx.onTouchStart/Move/End`（adapter 会桥接到 addEventListener） | input.js |

## 三、UI 层适配（工作量最大）

本项目所有菜单/面板/HUD 都是 **DOM + CSS**，小游戏没有 DOM。两个方案：

- **方案 A（推荐）：改为 Canvas 绘制 UI**
  把 index.html 里的面板改为 game.js 内的简单 UI 状态机，用 canvas 画按钮矩形 + 文字，
  触摸坐标做点击判定。工作量约半天，性能最好。

- **方案 B：引入 UI 库**（如 mini-program 的 webview 组件）
  直接用 `<web-view>` 嵌入托管在服务器上的 H5 版本。几乎零改动，
  但体验版域名要在后台配置 request/downloadFile 合法域名，且 webview 内无法用小游戏支付/广告。

## 四、分包与体积

当前全部代码 < 200KB，远小于小游戏 4MB 主包限制，无需分包。
音效为 WebAudio 实时合成，无音频资源文件，无需处理音频格式兼容。

## 五、体验版发布流程

1. 开发者工具 → 上传代码 → 版本号备注
2. mp 后台 → 版本管理 → 开发版本 → 设为体验版
3. 后台 → 成员管理 → 添加体验成员（最多 15 人扫码体验）
4. 正式发布需要：软著或自审承诺、类目（休闲游戏）、版号问题咨询微信最新政策（休闲类目前可先上体验/安卓内测渠道）

## 六、推荐的渐进路线

1. 先把 H5 版部署到静态托管（GitHub Pages / Gitee Pages / Vercel），手机浏览器直接玩，验证手感
2. PWA 已配置好（manifest + sw.js），可"添加到主屏幕"当 App 用
3. 确认要上微信再走本指南；UI 改造时可先只做「开始/结算/暂停」三个必要面板的最简版
