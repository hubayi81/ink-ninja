# 部署上线指南

游戏为纯静态文件（无构建、无依赖），任意静态托管即上线。本地已建好 Git 仓库（main 分支）。

## 方案 A：GitHub Pages（推荐，配合已装好的 GitHub Desktop）

1. 打开 **GitHub Desktop** → `File` → `Add local repository` → 选择 `D:\zcodeProject\ink-ninja`
2. 点 **Publish repository**：
   - Name 填 `ink-ninja`
   - **不要勾选** "Keep this code private"（免费账号的 Pages 需要 Public 仓库）
3. 发布后打开仓库网页 → `Settings` → `Pages` → `Build and deployment` → `Source` 选 **`GitHub Actions`**
4. 仓库里的 `.github/workflows/deploy.yml` 会自动运行，约 1 分钟后上线：
   **`https://<你的用户名>.github.io/ink-ninja/`**

以后每次在 GitHub Desktop 里 commit + Push，网站自动更新。

## 方案 B：Netlify 拖拽（最快，30 秒）

1. 打开 https://app.netlify.com/drop
2. 把 `ink-ninja` 整个文件夹拖进去
3. 立即得到 `https://随机名.netlify.app` 公网地址（可在设置里改名）
   - `netlify.toml` 已配好缓存策略，直接生效

## 方案 C：Vercel

1. https://vercel.com 注册 → `Add New Project`
2. 推送 GitHub 仓库后一键导入（或本地 `npx vercel`，需 Node）
3. `vercel.json` 已配好 `sw.js` 不缓存的头，更新即时生效

## 方案 D：Cloudflare Pages（国内访问通常最稳）

1. https://dash.cloudflare.com → `Workers & Pages` → `Create` → `Pages` → `Direct Upload`
2. 拖入文件夹或连接 GitHub 仓库即可，无需任何配置

## 各平台国内可访问性参考

| 平台 | 国内直连 | 备注 |
|------|----------|------|
| Netlify | 一般（偶尔慢） | 最快上手 |
| Vercel | 一般（偶尔慢） | 配置最完善 |
| Cloudflare Pages | 较好 | 推荐备用 |
| GitHub Pages | 不稳定 | 需要时可用 CF 做前置 |

## 更新注意

- `sw.js` 的离线缓存按版本号（`inkninja-v4`）失效——每次改动游戏文件后，把 `sw.js` 里的 `CACHE` 版本号 +1 再提交，玩家端才会拿到新版本（Vercel/Netlify 配置里已对 `sw.js` 关闭 HTTP 缓存）
- 所有资源路径均为相对路径，子路径部署（如 GitHub Pages 的 `/ink-ninja/`）无需改动
